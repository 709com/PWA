# 議員のタイマーと区の情報入口（/giin/）

たかはまなおき個人が作成したものです。文京区議会の公式のものではありません。

- 公開後のアドレス：https://709com.github.io/PWA/giin/
- 画面は3つ：タイマー（予算・決算審査／本会議30分）、区の情報入口（リンク集）、電話番号早見
- トップページ（PWA実験室の一覧）には載せず、別の入口にしています

## 守っていること
| 項目 | 内容 |
|---|---|
| 通信 | 入力内容は端末の中だけに保存。外へ送る命令はなし。画面の設定（コンテンツセキュリティポリシー）で外部への通信を止めている |
| 音・振動 | 出さない。残り5分・1分・超過は、色＋枠の形＋文字で知らせる |
| 取り込み | 文字と数字の入力だけ。写真・PDF・音声・映像の取り込み、撮影・録音・録画はなし |
| 持ち出し | 記録は「文字で表示する」→「コピーする」だけ。ファイルの書き出しはなし |
| 消去 | 「このアプリ」→「全データを消す」（貸与端末の返却用） |
| 載せる情報 | 文京区・文京区議会の公式サイトに公開されているものだけ。職員の個人名・内線番号は載せない。議員名簿と議会日程は写しを持たずリンクにする |

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面／見た目／動き |
| `data.js` | リンク集と電話番号（出典と確認日つき） |
| `sw.js` / `manifest.json` / `icon-*.png` | 通信なしで開く仕組み／ホーム画面用の設定とアイコン |
| `tools/check.mjs` | 公開前の自動点検（GitHubに送るたびに動く） |
| `tools/linkcheck.mjs` | リンク切れの自動点検（毎月3日に動く。切れていたらGitHubからメールが届く） |

## 直すときの決まり
1. 直したら `app.js` の `APP_VERSION` と `sw.js` の `VERSION` を同じ番号に上げる（使っている人の画面に「新しい版があります」と出る）
2. リンクや電話番号を直したら、公式サイトで実際に開いて確かめ、`data.js` の `kakunin`（確認した日）も直す。推測でアドレスを書かない
3. `node giin/tools/check.mjs` が「点検OK」になることを確かめる
4. **選挙の期間（告示日〜投票日。2027年4月18日の見込み〜4月25日）は、公開している内容を更新しない。** 自動点検もこの期間は失敗になる。告示日は区の公表で確かめ、`tools/check.mjs` の `QUIET` を直す
5. 既存の機能と重なるもの（資料の閲覧、メモ、質問カード、答弁の記録、名簿の写し、ファイル取り込み、AIの呼び出し）は足さない
