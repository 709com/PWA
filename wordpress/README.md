# 現在地（最寄駅）表示：設定の手順書

## 現在の状況（2026年10月30日時点）
| 項目 | 状態 |
|---|---|
| 第1部：WordPressへのプラグインの導入・合言葉の設定・地図のページ | 完了（ロリポップ。サイドバー「いまの現在地」に表示） |
| 第2部 2-1〜2-2：ショートカット「現在地を送る」の作成と手動での送信 | 完了（送信と地図への表示を確認） |
| 第2部 2-3：8時〜20時の自動実行（オートメーション13個） | **未登録。後日登録する** |
| 位置情報の許可 | ショートカットアプリは「このアプリの使用中」（「常に」は選べないため） |
| 地図のデザイン | 1.1.0で淡色地図に変更。文京区の境界と区内の駅を表示 |

### プラグインを新しい版にするとき
1. 新しい `genzaichi.zip` をダウンロードする
2. 「プラグイン」→「新規プラグインを追加」→「プラグインのアップロード」で、そのzipを選んで「今すぐインストール」
3. 「すでにインストールされています」と出たら「**アップロードしたもので置き換える**」を押す
4. 合言葉・設定・履歴はそのまま残ります

iPhoneの「ショートカット」アプリが、決まった時刻に現在地をWordPressへ送ります。WordPressのプラグインが最寄駅を計算し、ホームページに地図と文字で表示します。

- 保存するのは「駅名・駅の位置・時刻」だけです。iPhoneから届いた正確な位置は保存しません。
- 履歴は過去7日分を残し、古い分は自動で消えます。
- 合言葉を知らない人は、位置を書き込めません。合言葉はこのリポジトリには入っていません。

## 第1部：WordPressにプラグインを入れる

1. 次のファイルをパソコンでダウンロードします（zipのまま使います。開かなくて大丈夫です）
   https://709com.github.io/PWA/wordpress/genzaichi.zip
2. WordPressの管理画面で「プラグイン」→「新規プラグインを追加」を開きます
3. 上の「プラグインのアップロード」→「ファイルを選択」で、ダウンロードしたzipを選びます
4. 「今すぐインストール」→「プラグインを有効化」を押します
5. 左のメニューの「設定」→「**現在地表示**」を開きます
6. 「合言葉」に、12文字以上の合言葉を入れて「保存する」を押します
   - 他の場所で使っているパスワードとは別のものにしてください
   - 合言葉は、第2部でiPhoneにも入れるので、控えておいてください
7. 同じ画面の「iPhoneのショートカットに入れる送り先」に出ているURLを控えます
   （例：`https://あなたのサイト/wp-json/genzaichi/v1/update`）

### 地図を表示する
1. 地図を載せたい固定ページ（または投稿）を編集します
2. ブロックの「＋」→「ショートコード」を選び、`[genzaichi]` と入力します
3. 「更新」を押します
   - 地図の高さを変えたいときは `[genzaichi height="500"]` のように書きます

## 第2部：iPhoneのショートカットをつくる

iOSのバージョンによって、ボタンの名前や位置が少し違うことがあります。

### 2-1. 「現在地を送る」ショートカット
1. 「ショートカット」アプリを開き、下の「ショートカット」→ 右上の「＋」を押します
2. 一番上の名前を押して「**現在地を送る**」にします
3. 「アクションを検索」で「**現在地を取得**」を探して追加します
4. 続けて「**URLの内容を取得**」を探して追加します
5. 「URL」の部分を押し、第1部の7で控えた送り先URLを入れます
6. 「URLの内容を取得」の横の「＞」（または「詳細を表示」）を押し、次のように設定します
   - 方法：**POST**
   - 本文を要求：**JSON**
   - 「新規フィールドを追加」→「テキスト」を3回追加し、次のとおり入れます

   | キー | 値 |
   |---|---|
   | `key` | 合言葉（第1部の6で決めたもの） |
   | `lat` | 「現在地」の変数を選び、もう一度押して「**緯度**」を選ぶ |
   | `lon` | 「現在地」の変数を選び、もう一度押して「**経度**」を選ぶ |

7. 動作確認用に「**通知を表示**」を追加し、中身に「URLの内容」の変数を入れます
8. 右上の「完了」を押します

### 2-2. 試しに動かす
1. 「現在地を送る」を押して実行します
2. 位置情報の許可を求められたら「**常に許可**」を選びます（自動で動かすために必要です）
3. 「○○駅（約○m）として記録しました。」と通知が出れば成功です
4. ホームページの地図に印が出ることを確かめます

うまくいかないときは、下の「困ったとき」を見てください。

### 2-3. 毎時、自動で動かす（8時〜20時）
1. ショートカットアプリの下の「**オートメーション**」→「＋」（または「新規オートメーション」）を押します
2. 「**時刻**」を選び、時刻を **8:00**、繰り返しを「**毎日**」にします
3. 「**すぐに実行**」を選びます（「実行前に確認」だと自動になりません）
4. 「実行時に通知」をオフにします（自動実行のたびに出るお知らせを止めるため）
5. 「次へ」を押し、実行するショートカットに「**現在地を送る**」を選んで完了します
6. 同じ手順を、**9:00、10:00 … 20:00** まで繰り返します（全部で13個）

※ iPhoneの仕組み上、「毎時」という設定がないため、時刻ごとに1つずつつくる必要があります。

### 2-4. 仕上げ
動作が確認できたら、2-1でつくった「通知を表示」を削除しておくと、毎時のお知らせが出なくなります。

## 困ったとき

| 通知の内容・状態 | 原因と対処 |
|---|---|
| 「合言葉が違います。」 | ショートカットの `key` と、WordPressの合言葉が一致していません。WordPress側で合言葉を入れ直して保存し、ショートカットにも同じものを入れてください |
| 「合言葉が管理画面で設定されていません。」 | 第1部の6を行ってください |
| 「位置（緯度・経度）が読み取れません。」 | `lat` と `lon` に、緯度・経度の変数が入っているか確かめてください |
| 「送信の間隔が短すぎます。」 | 20秒以上あけてから送ってください |
| 403 Forbidden、または英語のエラー画面の文章が返ってくる | ロリポップの「WAF」（不正な通信を防ぐ仕組み）にはじかれている可能性があります。ロリポップの管理画面の「セキュリティ」→「WAF設定」で「ログ」を確認し、はじかれていれば、そのドメインのWAFを無効にして試してください。無効にすると守りが弱くなるので、判断に迷う場合はご相談ください |
| 404 Not Found | プラグインが有効になっているか確かめてください |
| 地図が「現在地を読み込めませんでした。」 | セキュリティ系のプラグインが、WordPressのREST API（外部とのやりとりの窓口）を止めていないか確かめてください |

## 公表を止めたいとき
- 一時的に止める：「設定」→「現在地表示」の「一時停止する」にチェックして保存
- 履歴を消す：同じ画面の「履歴をすべて消す」
- 完全にやめる：ショートカットのオートメーションを削除し、プラグインを「停止」→「削除」（設定と履歴も消えます）
