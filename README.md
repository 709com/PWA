# PWA実験室

iPhoneのホーム画面に追加して使うWebアプリ（PWA）を、1つずつ作って試すためのリポジトリです。

- 公開ページ：https://709com.github.io/PWA/
- アプリは1つにつき1フォルダ（例：`/water/`）。トップページ `index.html` にアプリ一覧があります。

## 方針
- 外部ライブラリは使わず、1アプリ数ファイルで作る
- アプリで入力したデータは、原則としてiPhoneの中だけに保存する（外部へ送信しない）
- 個人情報・APIキー・パスワードはコードに入れない（このリポジトリは公開されています）

## アプリ一覧
| フォルダ | 名前 | 試すPWA機能 |
|---|---|---|
| `/water/` | 水分・服薬カウンター | ホーム画面からの全画面起動、オフライン動作、端末内への保存 |
| `/timer/` | 文京区議会議員専用タイマー | 画面の消灯防止、音 |
| `/koe/` | 子どもの声の記録帳 | マイク（録音）、端末内データベース（IndexedDB）、共有メニュー |
| `/pomodoro/` | ポモドーロタイマー | 通知（アプリを開いている間）、アイコンの数字（バッジ） |
| `/push/` | プッシュ通知の実験 | 通知の許可、プッシュ通知の宛先づくり（サーバーは未接続） |
| `/monosashi/` | 文京区民専用ものさし | オフライン動作、共有メニュー（数字は出典つき・非公式） |

## WordPress用
| フォルダ | 名前 | 内容 |
|---|---|---|
| `/wordpress/` | 現在地（最寄駅）表示 | iPhoneのショートカットから送った現在地の最寄駅を、WordPressのページに地図で表示するプラグイン。手順書は `wordpress/README.md` |
