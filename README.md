# PWA実験室

iPhoneのホーム画面に追加して使うWebアプリ（PWA）を、1つずつ作って試すためのリポジトリです。

- 公開ページ：https://709com.github.io/PWA/
- アプリは1つにつき1フォルダ（例：`/water/`）。トップページ `index.html` にアプリ一覧があります。

## 方針
- 外部ライブラリは使わず、1アプリ数ファイルで作る
- アプリで入力したデータは、原則としてiPhoneの中だけに保存する（外部へ送信しない）
- 個人情報・APIキー・パスワードはコードに入れない（このリポジトリは公開されています）
