# 文京区民アプリ 〜本家・東京ドーム換算機〜（/bunkyo/）

会派「ぶんきょう子育て.ネット」が作る、文京区民向けの冗談アプリです。文京区・文京区議会の公式のものではありません。株式会社東京ドームとは関係ありません。

- 公開アドレス：https://709com.github.io/PWA/bunkyo/ （テスト公開中・検索よけあり）
- 6つのタイルのうち、いまは①東京ドーム換算機だけが開いています。②〜⑥は「近日開店」です。
- 設計メモ（先行事例の分析と画面の決まり）：`docs/sekkei.md`

## ファイル
| ファイル | 役割 |
|---|---|
| `config.js` | 設定。タイルの開け閉め、お休みの切り替え、版番号 |
| `index.html` / `style.css` / `app.js` | 入口／見た目／骨組み（タイル画面・共通ページ・新しい版の知らせ） |
| `apps/dome.js` | ①東京ドーム換算機 |
| `data/units.js` | 換算に使う数字と出どころの一覧 |
| `sw.js` / `manifest.json` / `icon-*.png` | 通信なしで開く仕組み／ホーム画面用の設定とアイコン（自作） |
| `tools/check.mjs` | 公開前の点検 |

## 直すときの決まり
1. **機能を開けるとき**：`apps/` にファイルを足し、`config.js` の該当タイルを `status: 'open'` にして `files` にファイル名を書く。ほかの機能のファイルには手を入れない。
2. 直したら `config.js` と `sw.js` の `VERSION` を同じ番号に上げる（使っている人に「新しい機能が届きました」と出る）。
3. **数字**は、公式の資料を実際に開いて確かめたものだけを `data/units.js` に書く。出どころと確認した日も一緒に直す。確かめられないものは出さない。
4. **お休みの切り替え**は `config.js` の `PAUSE` の1か所。`force: true` で手動停止。`from`〜`to` の間は自動でお休み画面になる（いまは2027年4月18日〜25日の見込み。確定したら直す）。この期間と、その日の公開・更新はしない。
5. 使わないもの：区の紋章・シンボルマーク、「文の京」の名称、東京ドームのロゴ・写真、実在の人の写真、他社のロゴ、特定の作品を思わせる表現。運営者は会派名で表示し、個人名を前に出さない。
6. 利用者の情報は集めない。入力欄で個人情報を聞かない。外へ送る命令・端末への保存は足さない（現在地・マイク・傾きを使う機能は、その場の計算だけに使う）。
7. 公開前に `node bunkyo/tools/check.mjs` が「点検OK」になることと、iPhoneの幅の画面を自分の目で確かめる。
