## 2. このアプリの画面の決まり

先行事例から、次のとおり決めた。

| 決まり | 中身 | もとにした事例 |
|---|---|---|
| 入口は1画面・6タイルだけ | 2列×3段。iPhoneの1画面に収め、説明は1行（「窓口は6つ。番号の順に開きます」） | neal.fun、Squoosh、Omni |
| タイルは3点セット | 自作の線画＋名前＋一行説明。番号札（一番〜六番）つき | ラッコツールズ、アソビ大全 |
| 大きさの下限 | タイルは高さ138px以上（親指で押せる）。ボタンは高さ54px、押せる範囲44px以上。本文17px、最小12px（注記のみ） | デジタル庁、GOV.UK |
| 色は3つ | 紙の色・墨の色・朱（はんこ）。藍は「まじめな一言」とリンクだけ。暗い画面にも対応し、明暗差4.5:1以上 | Wordle、GOV.UK |
| まじめな枠、ふざけた中身 | 枠は公文書の型（明朝の見出し、二重線、文書番号「文換第一号」、窓口番号、角印、但し書き「概算です」）。ふざけるのは結果の一言と証明書だけ | ぐんまのやぼう、U5H、横浜市、Google |
| 準備中は「近日開店」の木札 | ひもで下がった札。押すと中身の予告がその場で開く（押しても何も起きない、を作らない） | アソビ大全 |
| 押したら設定なしで動く | 換算機は開いた時点で入力できる。主ボタンは「換算証明書にする」の1つ | 計測、PROXX |
| 手ぶらでも試せる | 「身近なものから選ぶ」ボタン | Squoosh |
| 戻り方は1種類 | どの画面でも左上の「‹ もどる」で6タイルへ。iPhoneの戻る操作も同じ動き | （先行事例では確かめられなかったため自前で決めた） |
| 軽く、通信なしで | 外部の部品・文字・絵は読み込まない。一度開けば電波なしで動く。入力は送らず、保存もしない | Starbucks、Excalidraw、Squoosh |
| 区の公式と誤解させない | 最上部に常に「テスト公開中　文京区の公式アプリではありません」。区の紋章・シンボルマーク・「文の京」の名称は使わない | U5H（逆の立場からの教訓） |

### まねした点・まねしなかった点（要約）
- まねした：①入口は静かに、遊びは中身に（neal.fun）　②まじめな行政の言葉×ばかばかしい結果（ぐんまのやぼう・U5H）　③押せる大きさ・文字の大きさの下限（デジタル庁）
- まねしなかった：①たくさん並べて縦に流す一覧　②始める前の設定や、中継ページ　③公的機関の色・書体・名称の流用

## 3. あとから足す機能のための作り

- 機能は `apps/` に1ファイルずつ。`config.js` の該当タイルを `status: 'open'` にしてファイル名を書けば開く。ほかの機能には手を入れない。
- 版番号（`config.js` と `sw.js` の `VERSION`）を上げると、使っている人に「新しい機能が届きました」と出る。
- お休みの切り替えは `config.js` の `PAUSE` 1か所（手動の切り替え＋日付での自動）。
- ②坂の水準器・③弥生コンパス・④区歌カラオケは、傾き・現在地・マイクの許可が要る。許可を求める直前に理由を一言出す部品を、開けるときに共通で用意する。
